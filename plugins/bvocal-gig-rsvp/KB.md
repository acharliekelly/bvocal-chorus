# Manage Gig RSVPs

The Gig RSVP dashboard puts past Gigs with active MailerLite groups first for
cleanup, then future published Gigs that still need a group. Use column
headings to sort the visible list. Past Gigs without a group are hidden.

Enable RSVP only for a published future Gig. Deleting a past Gig's group is a
single confirmed action. Deleting an upcoming Gig's group requires a separate
confirmation page showing its RSVP count.
